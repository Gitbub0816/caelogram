# Caelogram

<!-- impeccable:product-schema 1 -->

## Platform
Web console, remote MCP service, cross-platform CLI, portable agent integrations.

## Purpose and users
Developer teams using external AI coding agents with existing GitHub repositories. GitHub remains canonical. Caelogram supplies revision-bound structural context and controls proposed changes through validation and draft pull requests. It provides no coding model.

## Core workflow
Connect an existing repository through a tenant-bound GitHub App installation; map committed files; resolve a task; inspect bounded context and omissions; submit explicit edits; validate; acknowledge limitations; publish a service branch and draft PR. Local CLI mapping reads existing committed Git checkouts without executing repository code.

## Confirmed constraints
Private source is sensitive. No secret values in context. Explain evidence, uncertainty, omissions, and exact revision. Never silently apply a moved base. Static imports do not prove runtime reachability. Map density must match real indexed entities. Optimize accepted correct changes, not token reduction alone.

## Brand commitment
User-approved dark slate, lighter grays, golds, warm metallic accents. No blue. Astral spatial identity. Keep the heatmap and add a separate rotatable three-dimensional orbital view with textured stars and planets. The attached galaxy references establish depth and material, not permission to fabricate repository objects.

## Hosting
User selected Cloudflare. Workers serve the application and API; D1 stores metadata; private R2 stores encrypted payloads. Local SQLite remains the development adapter.

## Accessibility
Keyboard navigation, explicit controls, reduced-motion behavior, touch interaction, accessible component list, and a working renderer for devices without WebGL.

## Current boundary
Executable alpha. Browser OAuth onboarding, isolated execution of test suites, automated key rotation/retention, comprehensive language semantics, and live GitHub App acceptance testing remain launch work. No paid-plan or customer claims are established.
